# 中文个人博客复刻搭建计划 (基于 paul.ren 风格)

本计划旨在基于 Nuxt.js 4 和 Tailwind CSS，深度复刻 `paul.ren` (保罗的小窝) 的视觉风格与核心功能，打造一个兼具美观与高性能的现代化个人博客。

## 1. 技术选型 (Tech Stack)

*   **核心框架**: **Nuxt.js 4** (Vue 3 Composition API) - *现代化、高性能、SEO友好*。
*   **UI 样式**: **Tailwind CSS** - *原子化 CSS，快速构建响应式与深色模式*。
*   **内容管理**: **Nuxt Content v3** - *基于 Git 的 Headless CMS，支持 Markdown/MDC*。
*   **图标库**: **Nuxt Icon** (Iconify) - *海量图标按需加载*。
*   **动画交互**: **VueUse** (交互逻辑) + **CSS Transitions/Animations**。
*   **评论系统**: **Giscus** (基于 GitHub Discussions) 或 **Waline** (独立部署) - *本计划推荐 Giscus 以降低运维成本*。
*   **部署托管**: **Vercel** 或 **Netlify** - *自动化构建与全球 CDN*。

## 2. 视觉风格设计 (Visual Design)

### 2.1 配色方案 (Color Palette)
采用清新明快的配色，兼顾深色模式体验。
*   **主色调 (Primary)**: `Sky-500` 或 `Teal-500` (代表清新、生活气息)。
*   **中性色 (Neutral)**: `Slate` 或 `Gray` 系列 (用于文字与背景)。
*   **背景色**:
    *   Light: `bg-gray-50` (主背景), `bg-white/80` (卡片/导航栏，带磨砂效果)。
    *   Dark: `bg-gray-950` (主背景), `bg-gray-900/80` (卡片/导航栏)。
*   **强调色**: 用于标签、链接悬停，建议使用渐变色增强现代感。

### 2.2 布局与排版 (Layout & Typography)
*   **字体**: 优先使用系统字体栈 (`Inter`, `system-ui`, `PingFang SC`)，引用部分手写字体用于 Slogan。
*   **圆角与阴影**: 统一使用 `rounded-2xl` (大圆角) 和 `shadow-sm` / `hover:shadow-lg`，营造亲和力。
*   **响应式断点**:
    *   `sm` (640px): 手机适配，单栏布局。
    *   `md` (768px): 平板适配，双栏或导航栏展开。
    *   `lg` (1024px): 桌面适配，最大内容宽度 `max-w-6xl`。

## 3. 页面架构与组件拆分 (Architecture)

### 3.1 目录结构
```bash
app/
  components/     # 通用组件
    AppHeader.vue # 顶部导航 (Sticky + Blur)
    AppFooter.vue # 底部信息 (版权 + 社交链)
    PostCard.vue  # 文章卡片
    ProjectCard.vue # 项目卡片
    HomeHero.vue  # 首页首屏 (动态背景 + 介绍)
  layouts/
    default.vue   # 全局布局 (Header + Slot + Footer)
  pages/
    index.vue     # 首页 (聚合展示)
    blog/         # 文章模块
      index.vue   # 文章列表
      [slug].vue  # 文章详情 (ContentRenderer)
    projects/     # 项目模块
    moments.vue   # 瞬间模块 (瀑布流/Grid)
    about.vue     # 关于页面
content/          # Markdown 数据源
  blog/           # 博客文章
  projects/       # 项目文档
  moments/        # 瞬间记录 (JSON/YAML)
```

### 3.2 核心功能模块
1.  **首页 (Home)**:
    *   **Hero 区**: 动态问候语 + 背景动画 (Blob/Gradient)。
    *   **最新文章**: 展示最新的 3-6 篇博客。
    *   **生活瞬间**: 拍立得风格的照片墙组件。
    *   **音乐/项目**: 嵌入式音乐播放器样式展示或精选项目推荐。
2.  **文章系统 (Blog)**:
    *   列表页: 支持按标签 (Tag) 筛选。
    *   详情页: 目录 (TOC)、阅读进度条、代码高亮、上一篇/下一篇导航。
3.  **评论模块**: 集成 Giscus 组件，在文章和留言板底部加载。
4.  **全局搜索**: 使用 Nuxt Content 的搜索 API 实现即时搜索。
5.  **暗黑模式**: 顶部导航栏一键切换，持久化存储于 LocalStorage。
