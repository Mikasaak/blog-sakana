# 添加二级导航菜单与“语录”功能开发计划

根据您的需求，我们将对顶部导航栏进行改造，为“文章”栏目添加二级悬浮菜单（包含“博客”和“语录”），并开发全新的“语录”页面。

## 1. 导航栏改造 (AppHeader.vue)

### 目标
*   当鼠标悬停在“文章”图标上时，显示下拉菜单。
*   下拉菜单包含两个选项：
    1.  **博客** (`/blog`): 指向现有的文章列表页。
    2.  **语录** (`/notes`): 指向新开发的语录展示页。

### 实现细节
*   **数据结构更新**: 修改 `links` 数组，为“文章”项添加 `children` 属性。
*   **组件逻辑**: 使用 `Menu` 和 `MenuItem` 组件（或手写 Tailwind 样式）实现悬浮下拉效果。
*   **样式**: 下拉菜单应保持与 Header 一致的磨砂玻璃风格和圆角设计。

## 2. 语录功能开发 (Notes Feature)

### 2.1 内容模型定义 (`content.config.ts`)
*   新增 `notes` 集合 (Collection)，用于存储语录数据。
*   **Schema**:
    *   `content`: 语录正文 (Markdown/String)。
    *   `author`: 原作者。
    *   `source`: 出处 (如书籍、电影名)。
    *   `date`: 记录日期。
    *   `style`: (可选) 样式标记，用于区分不同颜色的引用块（如参考图中的多彩边框）。

### 2.2 语录页面开发 (`app/pages/notes/index.vue`)
*   **布局**: 采用 **瀑布流 (Masonry Layout)** 或 **响应式 Grid** 布局，模仿参考图中的卡片样式。
*   **视觉风格**:
    *   每个语录卡片左侧带有不同颜色的粗边框（红、蓝、绿、紫等）。
    *   卡片背景为白色（深色模式为深灰），带有轻微阴影。
    *   正文居中或左对齐，出处和作者右对齐显示在底部。
    *   支持“复制”或“分享”小功能（可选增强）。

### 2.3 数据源创建
*   在 `content/notes/` 目录下创建 JSON 或 YAML 文件，录入示例语录数据。

## 3. 开发步骤

### 第一步：配置与数据准备
1.  修改 `content.config.ts` 添加 `notes` 集合定义。
2.  创建 `content/notes/data.json` 或多个 `.md` 文件作为初始数据。

### 第二步：语录页面实现
1.  创建 `app/pages/notes/index.vue`。
2.  编写数据获取逻辑 (`queryCollection('notes')`)。
3.  实现多彩卡片样式，根据数据中的 `style` 字段或随机分配边框颜色。

### 第三步：导航栏交互升级
1.  修改 `AppHeader.vue`，支持二级菜单渲染。
2.  添加 CSS 动画，使下拉菜单平滑淡入淡出。

## 4. 验收标准
*   [ ] 顶部导航“文章”图标悬停能正确显示二级菜单。
*   [ ] 点击“语录”能跳转到 `/notes` 页面。
*   [ ] 语录页面展示多彩卡片，包含正文、出处和作者。
*   [ ] 响应式适配：移动端点击“文章”应展开子菜单或直接跳转（建议移动端保持点击跳转，在列表页提供切换入口，或在侧边栏菜单中展开）。
