# 你好 Nuxt!

这是我使用 Nuxt Content 编写的第一篇博客文章。使用 Markdown 编写内容并将其渲染为精美的页面非常简单。

## 为什么选择 Nuxt?

Nuxt 让构建 Vue 应用程序变得轻而易举。拥有以下功能：
- 文件系统路由
- 服务端渲染 (SSR)
- 静态站点生成 (SSG)

它是构建博客的完美选择。
