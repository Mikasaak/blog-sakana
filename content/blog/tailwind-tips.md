# 实用优先的 CSS

Tailwind CSS 彻底改变了我们编写 CSS 的方式。我们不再需要与类名和特异性作斗争，而是可以直接在 HTML 中组合样式。

## 主要优势

1. **快速开发**: 无需在 HTML 和 CSS 文件之间切换。
2. **一致性**: 使用预定义的设计系统。
3. **小体积**: PurgeCSS 移除未使用的样式。
